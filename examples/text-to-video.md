# 视频生成示例 Text-to-Video / Image-to-Video

使用 Agnes Video V2.0 模型生成视频内容。

## 文生视频 Text-to-Video

### 基础用法

```
用 Agnes 生成一段 5 秒的海浪拍打沙滩的视频
```

### 指定参数

```
用 Agnes 生成一段 5 秒的视频，720P，内容是：
一只猫在草地上追逐蝴蝶，阳光明媚，慢镜头效果
```

### 高质量提示词示例

#### 自然风景
```
用 Agnes 生成一段 5 秒的自然风景视频：
日出时分的山谷，云海翻涌，金色阳光穿过云层，
镜头缓慢向前推进，电影感，4K画质
```

#### 城市街景
```
用 Agnes 生成一段 5 秒的城市夜景视频：
东京涩谷十字路口，霓虹灯闪烁，行人和车辆穿梭，
雨夜，地面有积水反射灯光，赛博朋克风格
```

#### 抽象艺术
```
用 Agnes 生成一段 5 秒的抽象艺术视频：
流动的彩色液体，渐变的色彩从蓝色变成紫色再变成粉色，
柔和的光线，微距镜头，催眠效果
```

#### 产品展示
```
用 Agnes 生成一段 5 秒的产品展示视频：
一瓶香水瓶在旋转，黑色背景，聚光灯打在瓶身上，
玻璃反光，高端质感，慢动作
```

## 图生视频 Image-to-Video

### 基础用法

```
用 Agnes 让这张图片动起来，生成 5 秒视频
```

### 指定运动效果

```
用 Agnes 把这张风景照片变成视频，
让天空的云慢慢飘动，水面有涟漪，风吹动树叶，
5 秒，720P
```

### 人物动图
```
用 Agnes 让这张人物照片动起来，
让她眨眼微笑，头发轻轻飘动，5 秒
```

## 视频参数说明

| 参数 | 可选值 | 默认值 | 说明 |
|---|---|---|---|
| 分辨率 | `720p`, `1080p` | `720p` | 视频清晰度 |
| 时长 | 5-10 秒 | 5 秒 | 视频长度 |
| 帧率 | - | 24 fps | 每秒帧数 |

## 技巧提示

1. **描述动态** — 视频和图片不同，要描述"发生了什么动作"
2. **镜头语言** — 可以指定"推镜头"、"旋转"、"慢动作"等
3. **时长控制** — 默认 5 秒，复杂场景建议先试短时长
4. **耐心等待** — 视频生成通常需要 30 秒到 3 分钟
5. **图生视频参考** — 参考图片越清晰，生成效果越好
