# 文生图示例 Text-to-Image

使用 Agnes Image 模型根据文本描述生成图片。

## 基础用法

```
用 Agnes 生成一张赛博朋克风格的城市夜景图
```

## 指定尺寸

```
用 Agnes 生成一张 1920x1080 的风景壁纸，山川湖泊，日出
```

## 高质量提示词示例

### 人物肖像
```
用 Agnes 生成一张人像照片，年轻女性，金色长发，柔和自然光，
电影感色调，85mm镜头，浅景深，高清细节
```

### 产品图
```
用 Agnes 生成一张产品图，白色背景上的无线耳机，
专业摄影棚灯光，高反射材质，商业摄影风格，8K高清
```

### 概念艺术
```
用 Agnes 生成一张概念艺术图，未来主义太空站内部，
巨大的观景窗外是星云，蓝色调，科幻风格，细节丰富
```

### 插画风格
```
用 Agnes 生成一张水彩风格插画，森林中的小木屋，
秋天的颜色，温暖的光线，童话风格
```

## 可用尺寸

| 比例 | 尺寸 | 适用场景 |
|---|---|---|
| 1:1 | 1024x1024 | 头像、社交媒体方形图 |
| 1:1 | 768x768 | 普通方形图 |
| 1:1 | 512x512 | 缩略图 |
| 4:3 | 1024x768 | 横版配图 |
| 3:4 | 768x1024 | 竖版配图 |
| 3:2 | 1536x1024 | 宽屏横图 |
| 2:3 | 1024x1536 | 竖版长图 |

## 技巧提示

1. **越具体越好** — 描述风格、光线、色调、构图、视角等细节
2. **风格关键词** — 可以指定"电影感"、"水彩"、"像素风"、"赛博朋克"等风格
3. **质量关键词** — 添加"高清"、"8K"、"细节丰富"、"专业摄影"等提升画质
4. **负面描述** — 如果不想要某些元素，可以在描述中说明
