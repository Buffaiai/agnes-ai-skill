# 图生图示例 Image-to-Image

使用 Agnes Image 模型基于参考图片进行风格转换和再创作。

## 基础用法

```
用 Agnes 把这张图片改成水彩画风格
```

## 风格转换示例

### 动漫风格
```
用 Agnes 把这张照片转换成吉卜力动画风格
```

### 油画风格
```
用 Agnes 把这张图片变成梵高油画风格，笔触明显
```

### 像素风
```
用 Agnes 把这张图片转换成 16-bit 像素艺术风格
```

### 素描风格
```
用 Agnes 把这张图片变成铅笔素描效果
```

## 场景变换示例

### 季节变换
```
用 Agnes 把这张夏天的街道照片改成冬天雪景
```

### 时间变换
```
用 Agnes 把这张白天的城市照片改成夜晚霓虹灯效果
```

### 环境变换
```
用 Agnes 把这张产品图的背景换成简约现代风格的室内场景
```

## 技巧提示

1. **描述目标风格** — 明确告诉模型你想要的最终效果
2. **保留主体** — 如果想保持原图主体不变，可以说明"保持人物不变"
3. **参考图片** — 确保提供的图片清晰，主体突出效果更好
4. **强度控制** — 可以用"稍微"、"强烈"等词调整风格化程度
